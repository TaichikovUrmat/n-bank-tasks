# N-bank Tasks — тестовое задание (Frontend)

SPA «Список задач»: фильтрация, поиск, пагинация, создание и редактирование задач.

## Стек

- Vue 3 (Composition API, `<script setup>`) + TypeScript
- Pinia — состояние, vue-router — маршрутизация, Vuelidate — валидация форм
- SCSS (общие переменные и миксины подключаются автоматически, см. `vite.config.ts`)
- Vite

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Прочие команды:

```bash
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр сборки
npm run typecheck  # только проверка типов
```

## Функциональность

**Список задач** (`/`)
- фильтры: статус, поиск (debounce 300 мс, по названию и описанию), исполнитель;
- постраничная навигация (по 8 задач);
- состояние фильтров и страницы хранится в URL (`?q=&status=&assignee=&page=`), поэтому
  ссылкой можно поделиться, а кнопки «назад/вперёд» работают;
- удаление с подтверждением, индикация просроченных задач.

**Создание / редактирование** (`/tasks/new`, `/tasks/:id/edit`)
- поля: `title`, `description`, `status`, `deadline`, `assignee`;
- валидация через Vuelidate (title 3–120 символов, обязательные status/deadline/assignee,
  дедлайн новой задачи не в прошлом).

## Архитектура

```
src/
  api/tasksApi.ts      мок REST API поверх localStorage (с задержкой, фильтрация и пагинация «на сервере»)
  stores/tasks.ts      Pinia-store списка (защита от гонок запросов)
  views/               страницы (список, форма)
  components/          фильтры, элемент списка, пагинация, бейдж статуса
  composables/         useDebouncedRef
  router/              маршруты (ленивая загрузка)
  styles/              SCSS-переменные и глобальные стили
  types/               доменные типы
```

Бэкенда нет: `src/api/tasksApi.ts` эмулирует его, данные (47 тестовых задач) сидируются при первом
запуске и сохраняются в `localStorage`. Чтобы сбросить данные — очистите ключ `n-bank:tasks:v1`.
Для подключения реального API достаточно заменить реализацию функций в этом файле.
